# Mac Sweep

一款中文 macOS 磁盘分析与清理应用。先帮你看看哪些文件占空间，再把你选择的旧文件移到废纸篓。扫描在本机完成，无需账户，不上传文件。

## 下载与打开

在 [GitHub Releases](https://github.com/dogeow/mac-sweep/releases/latest) 下载 `Mac-Sweep-v0.1.0-macos-arm64.zip`，解压后将 **Mac Sweep.app** 拖到「应用程序」文件夹并打开。

当前版本支持 **Apple Silicon Mac（M 系列芯片），macOS 12 或更新版本**。发布包使用本地 ad hoc 签名，没有 Apple Developer ID 签名或公证；macOS 可能阻止打开。若系统阻止运行，可先从源码构建。

## 三步整理你的 Mac

1. 打开「我的 Mac」，点击「开始检查」。检查只读取文件信息，不更改文件。
2. 点击「查看建议清理」，查看按应用和用途整理的结果。旧缓存和日志中的建议项会预先勾选；安装包、工具缓存和疑似应用残留需要你检查后选择。
3. 点击「检查并清理」，确认后把选中的文件移到废纸篓。

需要核实某项时，展开「查看文件并选择」或「查看文件详情」，也可以在 Finder 中查看。旧文件也可能仍有用途，清理前建议退出对应应用。**移到废纸篓后仍占磁盘空间**，确认文件不再需要后，再自行清空废纸篓。

## 想知道空间去哪里了？

打开「空间去哪里了」，选择一个位置并点击「查看大小」。文件夹按大小排列，点击可逐层查看，返回按钮回到上一级。占用图与更多统计按需展开，平时只看文件夹名称和大小即可。

目录分析只查看大小，不会把大文件自动列为清理项。文件夹总大小、建议清理大小和磁盘剩余空间分别显示；它们不代表同一件事。

## 隐私与清理规则

扫描与清理记录只保留在当前应用会话。应用没有永久删除功能；清理失败的项目会保留并显示原因。疑似残留仅是线索，可能包含设置、聊天记录或其他个人文件。

首次读取「下载」等目录时，macOS 可能询问权限。遇到无法读取的目录，应用会显示部分结果；如需更完整的分析，可在系统设置 → 隐私与安全性 → 完全磁盘访问权限中添加 Mac Sweep 并重新启动。无需管理员权限。

完整的扫描范围、保护规则、恢复方式和大小统计限制见 [安全与扫描说明](docs/SAFETY.md)。

## 从源码构建

需要 macOS 12 或更新版本、Xcode 命令行工具、Node.js 和 Rust 1.90 或更新版本。

```sh
git clone https://github.com/dogeow/mac-sweep.git
cd mac-sweep
npm ci
npm run test
npm run check
npm run build
```

应用生成在 `src-tauri/target/release/bundle/macos/Mac Sweep.app`。运行 `npm run dev` 可打开桌面开发版。本项目使用 Tauri 2 与 Rust；浏览器预览不能读取本机磁盘或执行清理。
