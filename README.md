# Mac Sweep

一款中文 macOS 磁盘分析与清理应用。先帮你看看哪些文件占空间，再把你选择的旧文件移到废纸篓。扫描在本机完成，无需账户，不上传文件。

## 下载与打开

在 [GitHub Releases](https://github.com/dogeow/mac-sweep/releases/latest) 下载 `Mac-Sweep-v0.1.7-macos-arm64.zip`，解压后将 **Mac Sweep.app** 拖到「应用程序」文件夹并打开。

当前版本支持 **Apple Silicon Mac（M 系列芯片），macOS 12 或更新版本**。发布包使用本地 ad hoc 签名，没有 Apple Developer ID 签名或公证；macOS 可能阻止打开。若系统阻止运行，可先从源码构建。

双击应用顶部的空白或标题区域，可按 macOS 的标题栏设置放大或还原窗口；按钮和输入控件不会触发缩放。

## 三步整理你的 Mac

1. 打开「我的 Mac」，点击「开始检查」。检查只读取文件信息，不更改文件。
2. 点击「查看建议清理」，查看按应用与用途合并的简洁列表，直接查看大小和选择状态。旧缓存和日志中的建议项会预先勾选；安装包、工具缓存和疑似应用残留需要展开检查后选择。
3. 点击「清理所选」，确认后把选中的文件移到废纸篓。

展开应用组后，先按文件夹汇总显示大小和项目数。点开目录可继续查看子目录，再按需查看文件；文件名称、大小和选择状态用紧凑列表显示，原因与完整路径收在文件信息中。目录复选框只选择当前筛选下已经扫描出的候选项，跨文件页的选择会保留，不会删除目录里未列出的内容。搜索和筛选收在「更多」中。

旧文件也可能仍有用途，清理前建议退出对应应用。**移到废纸篓后仍占磁盘空间**，确认文件不再需要后，再自行清空废纸篓。

清理后会在页面底部显示简洁结果，可直接打开废纸篓或查看移动记录。记录按需展开；关闭提示后，仍可从底部的「查看移动记录」找回入口。

## 想知道空间去哪里了？

打开「空间去哪里了」，在顶部从常用位置选择，或点击「自选文件夹」，二选一后点击「开始分析」。文件夹按大小排列，点击可逐层查看，返回按钮回到上一级；在顶层或尚未分析时，返回「我的 Mac」。默认只显示文件夹名称和大小；占用图、排序和详细信息收在「更多」中。扫描时显示动画进度条、预计百分比、实际文件数、已统计大小和用时。百分比按实际遍历工作估算，目录规模未知时先显示准备动画；没有新读数时不会伪增进度。重新查看时，会明确标出保留的是上次结果。

选择「整个磁盘」时，底部会分别显示 **系统已用**、**已定位文件** 和 **未定位空间**。其他 APFS 卷及未归到文件夹的空间单独列出，点击可查看说明，不能直接清理。未定位空间可能包括访问受限的文件、快照和文件系统开销。

目录分析会继续遍历直到完成或由你停止；无法访问的目录会跳过并提示。不再因为达到 200 万个条目或运行 5 分钟而自动停止。列表为保持流畅只展开部分子项；未展示文件的已读取大小仍计入总数。共享块可能导致文件块统计超过系统计量，此时应用会显示计量差异，不把两者差额当成未定位空间。

若 macOS 未及时返回文稿、音乐等个人文件或应用数据目录的内容，应用会跳过该部分并保留提示，继续统计其他目录。完全磁盘访问权限不能替代其他系统访问限制。

云盘的在线占位内容不会为扫描主动下载。已保存在本机的云盘文件仍会统计，云端显示的文件大小不代表本机已占空间。

目录分析不会把大文件自动列为清理项。可以在文件或文件夹上右键，在 Finder 中定位，或明确确认后移到废纸篓。移动整个文件夹会包括未展开、未统计的内容；系统位置与重要用户根目录只允许查看。文件夹占用、建议清理大小和系统磁盘容量分别统计；它们都不代表清理后一定能释放的容量。

进入已分析的目录时会复用已有大小统计，先显示直属文件与文件夹，不自动重扫整个目录。未缓存的大小显示为「待分析」；需要更新完整占用时，再点击「完整分析」。如果系统未返回当前目录的列表，会先显示已有统计中的直属子目录，并提示列表可能有遗漏。

如果你在 Finder 中移动或删除了文件，再点击旧项目时，应用会更新当前层的列表；当前目录已消失时，会返回可用的上级。此前的大小会标为「需更新」，再次完整分析后才更新占用，避免把移到废纸篓误算为已释放空间。

常看的目录可以收藏：点击文件夹行旁的星标，或进入目录后点击顶部「收藏」。侧栏「收藏目录」可以随时点击进入，重启应用后仍保留。已有统计会优先复用；首次打开或统计已过期时，也会先显示当前层的内容，未统计的目录大小显示「待分析」。点击「完整分析」才重新计算占用。点击收藏旁的 × 只取消收藏，不删除目录。

## 隐私与清理规则

扫描与清理记录只保留在当前应用会话。收藏的目录路径单独保存在本机应用配置中，不保存扫描结果或上传文件。应用没有永久删除功能；清理未完成的项目会保留选择并显示原因，文件状态以 Finder 为准。疑似残留仅是线索，可能包含设置、聊天记录或其他个人文件。

首次读取「下载」等目录时，macOS 可能询问权限。遇到受保护目录，应用会显示部分结果和「查看访问权限」。点击后会打开系统设置；由你在隐私与安全性 → 完全磁盘访问权限中添加并允许 Mac Sweep，然后重新打开应用、重新扫描。应用不会自动授予权限，也不会以管理员身份扫描。

完整的扫描范围、保护规则、恢复方式和大小统计限制见 [安全与扫描说明](docs/SAFETY.md)。

## 从源码构建

需要 macOS 12 或更新版本、Xcode 命令行工具、Node.js 和 Rust 1.90 或更新版本。

```sh
git clone https://github.com/dogeow/mac-sweep.git
cd mac-sweep
npm ci
npm run test
npm run check
npm run build
```

应用生成在 `src-tauri/target/release/bundle/macos/Mac Sweep.app`。运行 `npm run dev` 可打开桌面开发版。本项目使用 Tauri 2 与 Rust；浏览器预览不能读取本机磁盘或执行清理。
